# Keerthish G — Portfolio (作品集)

`public/index.html` is the complete website. All 27 portfolio pages are embedded in it
at full resolution, so no other files are needed.

Deploy on Vercel: import this folder (preset "Other", no build command). `vercel.json`
already sets the output directory to `public`.

To update the portfolio pages, send the new PDF to Claude to regenerate index.html.
